# Torch Tool

A compact Flutter flashlight: a big glowing lens with four brightness presets
(Low / Med / High / Max), a power toggle, and an animated SOS strobe that
flashes the Morse pattern · · · – – – · · ·. All state is in-memory
(ChangeNotifier) — the beam is simulated on screen, so it runs anywhere
Flutter runs, with Material 3 light and dark theming.

## Run

    flutter pub get
    flutter run

## Test

    flutter test
